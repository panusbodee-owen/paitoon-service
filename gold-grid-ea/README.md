# Robbins Gold Grid EA v2.00 (XAUUSD, MetaTrader 5)

EA เทรดทองคำบนกราฟ M15 ตามเทรนด์ H1 เข้าไม้เมื่อราคาย่อตัวและมีแท่งเทียนยืนยัน แล้ววางไม้แบบ Grid ในโซนย่อตัว ทุกไม้เสียได้ไม่เกินจำนวนเงินที่ตั้ง และได้ 3 เท่าเมื่อชนะ (RR 1:3) **แพ้ครบ 3 ไม้ในวันไหน หยุดเทรดวันนั้นทันที**

> EA รับประกันได้ว่าทำงานตามกติกาที่ตั้งไว้ แต่ไม่รับประกันกำไร ควรทดสอบใน Strategy Tester และบัญชี Demo ก่อนใช้เงินจริง

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `RobbinsGoldGrid.mq5` | ตัว EA (ไฟล์เดียว พร้อม compile) |
| `presets/RobbinsGoldGrid_v2_Default.set` | ค่าตั้งต้น: เสีย 5 / ได้ 15, หยุดหลังแพ้ 3 ไม้ |
| `sim/` | ตัวจำลองตรรกะ (Python) + ชุดทดสอบ |

## 1. ติดตั้งและ Compile

1. เปิด MT5 แล้วไปที่ **File → Open Data Folder** แล้วคัดลอก `RobbinsGoldGrid.mq5` ไปไว้ใน `MQL5\Experts\`
2. คัดลอก `presets\*.set` ไปไว้ใน `MQL5\Presets\` (ไม่บังคับ)
3. เปิด MetaEditor (F4) แล้วเปิดไฟล์และกด **F7** ต้องขึ้น `0 errors` ถ้ามี error ให้ส่งข้อความในแท็บ Errors กลับมา
4. ลาก EA ลงกราฟ **XAUUSD M15** แล้วเปิด Algo Trading

**ข้อกำหนด:**
- ต้องเป็นบัญชี **Hedging**
- พอร์ตเล็กอย่าง 30$ ควรใช้ leverage ≥ 1:500 เพราะ 0.01 lot ของทองใช้ margin ประมาณ ราคาทอง ÷ leverage ต่อไม้ (ทอง 4,000$ ที่ 1:500 ≈ 8$ ต่อไม้) ถ้า margin ไม่พอ EA จะข้ามไม้นั้น

## 2. วิธีอ่านกราฟและเข้าไม้

```
1) H1 เทรนด์       EMA50 > EMA200, EMA50 กำลังขึ้น (เทียบ 3 แท่งก่อน), ADX >= 20  -> BUY เท่านั้น
                   (กลับด้านทั้งหมด -> SELL เท่านั้น / ไม่ชัด -> ไม่เทรด)
2) M15 ย่อตัว       ใน 6 แท่งล่าสุด ราคาเคยแตะ EMA20 และ RSI(14) เคยลงถึง <= 40
3) โซนยังไม่แตก     แท่งล่าสุดปิดเหนือ EMA50
4) แท่งยืนยัน      Bullish Engulfing หรือ Pin bar (ไส้ล่าง >= 2 เท่าของ body และปิดในช่วงบน 40%)
                   และ RSI กำลังหันขึ้น
5) ความผันผวน       ถ้า ATR > 2 เท่าของค่าเฉลี่ย ไม่เข้า (ช่วงข่าวแรง / กระชาก)
6) SL               ใต้จุดต่ำสุดของการย่อตัว - 0.2 ATR (ใช้ SL เดียวกันทุกไม้ใน setup)
                   ข้าม setup ถ้า SL กว้างเกิน 3 ATR หรือเกิน 20$
```

### Grid ใน setup เดียว

| ไม้ | เข้าที่ | SL | TP |
|---|---|---|---|
| 1 | ราคาตลาด ทันทีหลังแท่งยืนยันปิด | SL ร่วม | 3 × ระยะ SL ของไม้นี้ |
| 2 | Buy Limit ต่ำกว่าไม้ 1 = 0.3R | SL ร่วม | 3 × ระยะ SL ของไม้นี้ |
| 3 | Buy Limit ต่ำกว่าไม้ 1 = 0.6R | SL ร่วม | 3 × ระยะ SL ของไม้นี้ |

ตัวอย่าง BUY E1 = 4000, SL = 3995 (R1 = 5$):

| ไม้ | Entry | SL | TP | พอร์ต 30$ (เสีย 5/ไม้) | พอร์ต 10,000$ ตั้ง `InpRiskMoney=100` |
|---|---|---|---|---|---|
| 1 | 4000.0 | 3995 | 4015 | 0.01 lot: เสีย 5 / ได้ 15 | 0.20 lot: เสีย 100 / ได้ 300 |
| 2 | 3998.5 | 3995 | 4009 | 0.01 lot: เสีย 3.5 / ได้ 10.5 | 0.28 lot: เสีย 98 / ได้ 294 |
| 3 | 3997.0 | 3995 | 4003 | 0.02 lot: เสีย 4 / ได้ 12 | 0.50 lot: เสีย 100 / ได้ 300 |

- **Lot:** คำนวณให้แต่ละไม้เสียไม่เกิน `InpRiskMoney` และปัดลงเสมอ ถ้า 0.01 lot ยังเสียเกินที่ตั้ง EA จะ**ข้ามไม้นั้น** (พอร์ต 30$ กับ SL เกิน 5$ ไม้ 1 จะถูกข้าม แต่ไม้ 2–3 ที่อยู่ลึกกว่ายังเข้าได้)
- **ยกเลิกไม้ที่ยังรอ:** เมื่อมีไม้ใดใน setup ปิด, ผ่านไป 8 แท่ง, เทรนด์ H1 เปลี่ยน, หลุดช่วงเวลาเทรด หรือเข้าช่วงข่าว
- **RR 1:3 เสมอ:** ถ้าไม้ market ถูกเปิดที่ราคาคลาดไป (slippage) EA จะเลื่อน TP ใหม่ให้ได้ 3R พอดีจากราคาที่เปิดจริง
- **ไม่มี break-even:** ค่าเริ่มต้นปิดไว้ ทุกไม้จะออกที่ −1R หรือ +3R เท่านั้น (เปิดได้ที่ `InpUseBreakEven`)

## 3. กติกาต่อวัน

| กติกา | ค่าเริ่มต้น | ทำงานอย่างไร |
|---|---|---|
| แพ้ครบ N ไม้ หยุดวันนั้น | `InpMaxLossesPerDay = 3` | นับไม้ที่ปิดขาดทุนตั้งแต่ต้นวัน (เวลาเซิร์ฟเวอร์) ครบ 3 ไม้ EA ปิดทุกอย่างแล้วหยุดถึงวันใหม่ ถ้าต้องการให้หยุดที่ไม้ที่ 4 ตั้งเป็น 4 |
| จำนวนไม้ต่อ setup ไม่เกินโควตาแพ้ที่เหลือ | — | แพ้ไปแล้ว 2 ไม้ → setup ถัดไปวางได้แค่ 1 ไม้ เพราะไม้ใน setup เดียวกันใช้ SL ร่วมกัน ถ้าวาง 3 ไม้แล้วโดน SL พร้อมกันจะกลายเป็นแพ้ 5 ไม้ในวันเดียว |
| ขาดทุนรวมสูงสุดต่อวัน | 3 × `InpRiskMoney` | เช่น 15$ เมื่อเสียไม้ละ 5 |
| Equity hard-stop | `InpMaxDDPct = 0` (ปิด) | ตามที่ขอให้ตัด 30% ออก ถ้าต้องการเปิดกลับให้ใส่ % ที่ต้องการ |
| เป้ากำไรรายวัน | ไม่มี | เทรดตามสัญญาณได้ทั้งวัน |

## 4. Backtest

| ตั้งค่า | ค่า |
|---|---|
| Symbol / Timeframe | XAUUSD / **M15** |
| Modeling | **Every tick based on real ticks** |
| ช่วงเวลา | 2024-01-01 ถึงปัจจุบัน |
| Deposit | ทุนที่จะใช้จริง และตั้ง `InpRiskMoney` ให้สอดคล้อง |

**อ่านผลท้ายแท็บ Journal** EA จะสรุปไว้ให้ ตัวอย่าง:

```
[RGG] Bars evaluated: no trend 30000 | volatile 1200 | no pullback 9000 | rsi 5000 | zone broken 800 | no candle 2500 | SIGNAL 300 | data 0 |
[RGG] Setups 280 | signals skipped for SL distance 20 | layers placed L1 270 L2 190 L3 120 L4 0 L5 0
[RGG] Layers skipped: lot above risk 15 | margin 0 | budget 0 | days stopped by loss limit 40
[RGG] Layer 1: trades 270 | TP 80 (...) | SL 185 (...) | other 5 (...) | TP rate 29.6% (break-even 25%)
```

- **TP rate ต้องเกิน 25%** (บวกค่า spread/commission) ถึงจะมีกำไร ถ้าต่ำกว่านี้แปลว่าเงื่อนไขเข้าไม้ยังไม่มี edge
- `SIGNAL` น้อยมาก แปลว่าเงื่อนไขเข้มเกิน: ลองลด `InpADXMin` หรือเพิ่ม `InpRSIPullback` เป็น 45
- `no trend` สูงมากเป็นเรื่องปกติ เพราะ EA เทรดเฉพาะตอนที่ H1 มีเทรนด์ชัดเท่านั้น
- Optimize ด้วย criterion **"Custom max"**: EA คืนค่ากำไรสุทธิ ÷ max equity DD

## 6. Runbook

| เหตุการณ์ | EA ทำเอง | คุณควรทำ |
|---|---|---|
| แพ้ครบ 3 ไม้ | ปิดทุกอย่าง หยุดถึงวันใหม่ (`STOPPED FOR TODAY`) | ไม่ต้องทำอะไร |
| VPS หรือ MT5 ดับ | เปิดมาแล้วอ่านไม้และสถานะเดิมต่อได้ (SL/TP อยู่ที่เซิร์ฟเวอร์) | เช็กว่า Algo Trading ยังเปิดอยู่ |
| ไม้ไม่มี SL | ใส่ SL/TP ให้ทันที ถ้าใส่ไม่ได้จะปิดไม้ | ดู log |
| ราคา gap ข้าม SL | ไม้ถูกปิดที่ราคาตลาด อาจเสียเกินที่ตั้ง ถ้าขาดทุนรวมของ setup เกิน 110% ของงบ EA จะปิดทั้ง setup | ตั้ง `InpCloseAllFriday = true` ถ้าไม่อยากถือข้ามเสาร์-อาทิตย์ |
| `Layer skipped: the minimum lot would lose more than ...` | ข้ามไม้นั้น | ปกติสำหรับพอร์ตเล็กที่ SL กว้าง |

## 7. ทดสอบสูตรด้วย Python

```bash
cd gold-grid-ea/sim
python3 -m unittest -v
```

ชุดทดสอบตรวจว่า:
- ทุกไม้ RR = 3.00 รวมกรณีที่ต้องเลื่อน TP หลัง slippage
- ขาดทุนต่อไม้ไม่เกิน `InpRiskMoney` ทั้งพอร์ต 30$ และ 10,000$
- ไม่แพ้เกินจำนวนไม้ต่อวัน
- อ่าน Engulfing / Pin bar ถูก
- เงื่อนไขเข้าไม้ครบทุกข้อ ทั้ง BUY และ SELL

## 8. พารามิเตอร์หลัก

| Input | Default | ความหมาย |
|---|---|---|
| `InpRiskMoney` | 5.0 | เงินที่ยอมเสียต่อไม้ ชนะได้ 3 เท่า **ปรับเองเมื่อพอร์ตโต** |
| `InpMaxLossesPerDay` | 3 | แพ้ครบกี่ไม้แล้วหยุดวันนั้น |
| `InpGridLevels` | 3 | จำนวนไม้ต่อ setup (1–5) |
| `InpLayerStepR` | 0.3 | ระยะห่างระหว่างไม้ (× R1) |
| `InpADXMin` | 20 | ความแรงเทรนด์ขั้นต่ำ (สูงขึ้น = ไม้น้อยลงแต่คัดมากขึ้น) |
| `InpRSIPullback` | 40 | RSI ต้องย่อลงถึงระดับนี้ (SELL ใช้ 60) |
| `InpPullbackBars` | 6 | จำนวนแท่งที่ใช้ดูการย่อตัว |
| `InpMaxSLATR` / `InpMaxSL` | 3 / 20 | ข้าม setup ที่ SL กว้างเกิน |
| `InpMaxDDPct` | 0 | Equity hard-stop (0 = ปิด) |
| `InpUseBreakEven` | false | เลื่อน SL ไปที่ทุนเมื่อได้ 1R |
| `InpMaxSpread` | 0.50 | spread สูงสุดที่ยอมเข้าไม้ |
| `InpSessionStartHour` / `EndHour` | 7 / 21 | ช่วงเวลาเทรด (เวลาเซิร์ฟเวอร์) |
